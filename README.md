# Problem Solving Loop

一个用于处理生活、学习、工作和项目问题的动态问题解决 Skill。

它不会急着给建议，而是通过动态诊断，把模糊现象逐步转化为具体问题，识别当前最大阻碍，设计一个可测试的 Solution，并根据真实行动反馈持续迭代。

## 核心循环

现象 → 明确目标 → 动态诊断 → 问题分类 → 根因假设 → 当前最大阻碍 → Solution → 行动 → 反馈 → 迭代

## v1.1 最高原则

1. 持续把行动调试得更低阻力、更可持续、过程相对愉悦。持续痛苦、长期依赖意志力硬撑或明显无法维持，意味着方案本身需要继续诊断和迭代。
2. 如果执行不了，就一定要问出具体问题。不能停留在“拖延”“不想做”或“执行力差”等标签上。

这里的“低阻力”并不意味着所有行动都应毫无不适。正常的短期疲劳、陌生感和必要挑战可以存在；持续高阻力才是需要调试的信号。

## 使用方式
